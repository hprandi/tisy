# Before doing anything in this repo

Read [`ai/initial_prompt.md`](ai/initial_prompt.md) first. It contains the project context and the engineering working agreement (architecture principles, comment style, and the rule about confirming a plan before implementing) that governs how work gets done here. Follow it.

# Roadmap

The roadmap, open decisions and status live in the GitHub Project [Ingressos — MVP](https://github.com/users/hprandi/projects/1) (repo `hprandi/tisy`), not in this repository. Its README has the conventions (labels `step` / `decision` / `backlog`, columns, how to pick work); use `gh` to read and update issues. Issues labeled `decision` are the owner's to decide — present options, never decide or close them.
